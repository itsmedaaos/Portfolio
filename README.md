# Creative Portfolio — Starter

هذا إصدار مبدئي لموقع Portfolio باستخدام:
- HTML
- CSS
- JavaScript

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو افتح المجلد في VS Code واستعمل Live Server.

## بعد وصول ملف التصاميم
سيتم استبدال:
- YOURNAME بالاسم/البراند الحقيقي.
- الصور الوهمية بالتصاميم الفعلية.
- التصنيفات حسب نوع الأعمال الموجودة.
- الألوان والخطوط حسب الهوية البصرية.
- بيانات التواصل وروابط السوشيال.
- نص About Me والخدمات.

الهيكل الأساسي:
- index.html
- css/style.css
- js/script.js
- assets/images/ ← ضع فيه الصور لاحقًا

## PDF Portfolio Section

The portfolio now includes a dedicated PDF Work section. Place your PDF files in `assets/pdfs/` and register them in the `pdfProjects` array at the top of `js/script.js`. Each project gets an online PDF viewer and a direct download button.
